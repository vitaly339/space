# Telegram-бот бронирования «Космос»

Готовая программа для `@MatkosmosBot`. Бот принимает заявки на свободные прыжки, дни рождения и групповые посещения, а администратор подтверждает или отклоняет заявку одной кнопкой.

## Что умеет бот

- выбор формата посещения;
- выбор даты на ближайшие 14 дней;
- ввод желаемого времени после 10:00;
- выбор 30, 60 или 120 минут;
- количество гостей и телефон;
- комментарий к заявке;
- отправка заявки администратору;
- подтверждение или отклонение заявки одной кнопкой;
- уведомление клиента о решении;
- цены, адрес и режим работы в меню.

## Секретные настройки

Никогда не публикуйте токен бота в GitHub и не отправляйте его в обычном чате.

| Переменная | Значение |
| --- | --- |
| `BOT_TOKEN` | Токен `@MatkosmosBot`, полученный в BotFather |
| `ADMIN_CHAT_ID` | Числовой ID администратора или группы, куда приходят заявки |
| `WEBHOOK_SECRET` | Длинная случайная строка; Render создаёт её автоматически |

## Первый запуск на Render

1. Загрузите этот проект в отдельный GitHub-репозиторий.
2. В Render выберите **New → Blueprint** и подключите репозиторий.
3. В поле `BOT_TOKEN` вставьте токен из BotFather.
4. В `ADMIN_CHAT_ID` сначала поставьте `0`.
5. Дождитесь запуска и откройте `@MatkosmosBot` в Telegram.
6. Нажмите **Запустить** и отправьте команду `/myid`.
7. Скопируйте число из строки «Ваш личный ID».
8. В Render откройте **Environment**, замените `ADMIN_CHAT_ID=0` на полученное число и выберите **Save and deploy**.
9. Снова нажмите **Запустить** и сделайте тестовое бронирование.

Если заявки должны приходить в рабочую группу, добавьте бота в эту группу, отправьте там `/myid` и используйте число из строки «ID этого чата».

## Локальная проверка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Экспортируйте значения `BOT_TOKEN` и `ADMIN_CHAT_ID`, затем запустите:

```bash
python bot.py
```

Без `WEBHOOK_BASE_URL` программа автоматически использует long polling. На Render она автоматически берёт публичный адрес из `RENDER_EXTERNAL_URL` и включает webhook.

Проверка программы:

```bash
python -m unittest -v
```

## Важно

Отправленная клиентом форма создаёт заявку, а не безусловную бронь. Место считается забронированным только после нажатия администратором кнопки **Подтвердить**.
